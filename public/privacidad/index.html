Qué datos y para qué

Si solicitas información o un presupuesto, puedes facilitar tu nombre, teléfono, correo electrónico y los detalles de tu proyecto. Estos datos se utilizan únicamente para atender la consulta, contactar contigo y, si lo solicitas, preparar una propuesta.

La base jurídica es la aplicación, a petición tuya, de medidas precontractuales. No se utilizarán estos datos para enviarte publicidad no solicitada.

Cómo se envía el formulario

Al enviar una solicitud, los datos de contacto y la descripción del trabajo se transmiten a FormSubmit para su envío al correo de Reformas Guadalajara. No se envía una respuesta automática a quien rellena el formulario.

Evita incluir datos sensibles que no sean necesarios para describir el trabajo.

Proveedores y datos técnicos

El sitio está alojado en Vercel, que puede tratar datos técnicos de conexión necesarios para servir y proteger la web. La tipografía se carga desde Google Fonts; al solicitarla, el navegador se conecta a servidores de Google y transmite la dirección IP necesaria para entregar el recurso. Consulta la política de privacidad de Google.

Para entregar las solicitudes, se utiliza FormSubmit para el correo electrónico y Google como proveedor del buzón destinatario. FormSubmit indica que conserva los envíos durante un máximo de 30 días. Estos proveedores tratarán los datos necesarios para entregar el correo, conforme a sus propias políticas y condiciones.

El código actual no incorpora herramientas de analítica, publicidad ni seguimiento. No se venden los datos personales.

Conservación

Los mensajes recibidos por correo se conservarán durante el tiempo necesario para gestionar la consulta. Si se inicia una relación contractual, podrán conservarse durante los plazos legales aplicables para atender obligaciones o responsabilidades.

Derechos

Puedes solicitar acceso, rectificación, supresión, limitación u oposición al tratamiento, así como la portabilidad cuando proceda, escribiendo a Tejadosycubiertasvaloria@gmail.com. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos.
